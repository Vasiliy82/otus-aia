# Production MVP (архитектура only)

На этапе PoC код MVP **не реализуется**. Здесь будет целевая архитектура:

- C4 Level 1–3
- Deployment Diagram (DMZ, Control Plane, Data Plane, GPU Zone, Observability)
- Sequence Diagram полного запроса
- ER для production (Neo4j cluster, Qdrant cluster, PostgreSQL, MinIO)
- Sizing / capacity planning
- Roadmap PoC → MVP → Production

Исходные наброски: локальный файл `Наработки/4. MVP.md`.

Связанный ADR: [007-poc-mocks-and-mvp-replacement.md](../adr/007-poc-mocks-and-mvp-replacement.md).
